# Movie Data Analysis Using Python

## Project Description

Movie Data Analysis is a Python-based data analysis project that explores movie-related data such as movie titles, genres, release years, ratings, and revenue.

The project uses Python and data analysis libraries to clean, analyze, and visualize the movie dataset. The analysis helps identify patterns, trends, popular genres, highly rated movies, and revenue-related insights.

## Objectives

* Analyze movie data using Python.
* Identify the highest-rated movies.
* Find movies with the highest revenue.
* Analyze movies based on genres.
* Analyze the number of movies released in different years.
* Calculate average movie ratings and revenue.
* Create visualizations to understand the data easily.

## Dataset

The dataset contains information about movies, including:

* Movie Title
* Genre
* Release Year
* Rating
* Revenue

The dataset is stored in the `movies.csv` file.
