# 🎬 Movie Data Analysis Using Python

## 📌 Project Overview

Movie Data Analysis is a Python-based data analysis project developed to explore and understand movie-related information such as ratings, genres, revenue, release years, votes, directors, and runtime.

The project uses Python libraries such as Pandas, Matplotlib, and Seaborn to clean, analyze, visualize, and extract meaningful insights from movie data.

---

## 🎯 Objectives

The main objectives of this project are:

- Analyze movie ratings and identify highly-rated movies.
- Identify the most common movie genres.
- Analyze movie releases across different years.
- Compare average ratings across genres.
- Identify movies with the highest revenue.
- Analyze revenue patterns across genres.
- Analyze directors based on the number of movies.
- Study movie runtime.
- Analyze relationships between rating, votes, revenue, and runtime.
- Create meaningful data visualizations.

---
